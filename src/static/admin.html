📥 JSON 批量导入

📋 格式说明：
• type: 题型，choice(选择) / judge(判断) / calc(计算)
• topic_name: 章节名称（不存在会自动创建）
• unit: 所属单元（可选，文化类科目用，如"三年级上册"）
• content: 题干内容（可用 \n 换行）
• options: 选项数组（选择题4个，判断题写 ["对","错"]，计算题写 null）
• answer: 答案。选择题/判断题填选项序号（从0开始），计算题填具体答案
• explanation: 错题讲解（可选，支持HTML标签如 <b>）
• difficulty: 难度1-5（可选，默认1）
[
  {"type":"choice","topic_name":"变量与标识符","content":"1+1=?","options":["1","2","3","4"],"answer":"1","explanation":"1+1=2","difficulty":1},
  {"type":"judge","topic_name":"注释","content":"# 是注释符号","options":["对","错"],"answer":"0","explanation":"对的"},
  {"type":"calc","topic_name":"加减法","content":"458+376=?","options":null,"answer":"834","explanation":"列竖式计算...","difficulty":2}
]
