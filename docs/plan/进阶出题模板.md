# 进阶（tier=2）出题模板与思路模式

> 适用科目：Python基础实操（subject_id=3，20 课 L1–L20 递进）。
> 用途：本文件是进阶题的**出题规范 + 可直接照填的模板**。下回要出进阶题，读本文即可，不必重新讨论机制。
> 核心前提：**进阶与初阶机制完全相同，唯一区别是题目更难、代码量更大、综合前面课的知识。** 不新增字段、不改评分、不改前端。

---

## 0. 一句话原则

进阶题 ≠ 新机制。它只是「初阶题的 harder 版本」：

- 同一题型（`code`）、同一评分（LLM ai评分）、同一 `explanation` 思路字段；
- 仅 `tier=2`、参考解 20–50 行（**出题目标，非评分标准**）、解法综合前面课知识。

**「代码行数」是出题时的目标体量，不是给孩子打分的依据。** 行数多是为了让孩子真正动手写、练到编码；拿行数当评分标准是没意义的，LLM 评分只看「是否达成题目要求、逻辑对不对、写法好不好」。出题时我们按目标体量去设计题目，但绝不把行数写进评分。

任何「加字段 / 加输出比对 / 改前端」的冲动，都是过度设计，已否决。

---

## 1. 出题机制（与初阶完全一致）

| 项 | 取值 | 说明 |
|---|---|---|
| `type` | `"code"` | 编程题，沙箱实跑 + LLM ai评分（同初阶） |
| `tier` | `2` | 进阶档位。组卷/掌握度/学情/积分已 tier 化，后端零改动 |
| `topic_id` | 课 N 的 topic_id | 本题**主要考察**的「课 N」，一题一归属（同初阶） |
| `difficulty` | `2` 或 `3` | 题内微难度，**不参与组卷/积分**，仅展示用 |
| `expected_output` | **`null`** | **留空**，评分全交给 LLM（见 §3） |
| `sample_input` | **input 类题必填** | ⚠️ 关键：凡参考解用到 `input()` 的题，**必须填 `sample_input`**（符合题目输入格式的样例，如 `"3\n5\n2\n"`）。评分沙箱用它作为 stdin 实跑代码；若留空，`input()` 会抛 EOFError → 运行报错 → LLM 给 0 分。**非 input 类题（纯 print）留空即可。** |

### 1.1 递进包含规则（方式 A：内容综合）

课 N 的进阶题，其**解法允许且应当综合 课1…课N 的全部知识点**：

- 题目的 `topic_id` 仍绑「课 N」；
- 但题干与参考解要自然用到 课1…课N-1 的知识（如 课7 进阶 = while + if 判断 + 累加）；
- 组卷选「课N + 进阶」即取 课N 的 tier=2 题，**后端零改动**；
- 掌握度按 `(学员, 课N, 进阶)` 计，正是「每课各自的进阶掌握度」。

> 不采用「组卷混合式」（选 课N 时拉 课1…课N 的题混合）——那会改组卷逻辑且掌握度语义变糊，已否决。

### 1.2 积分

进阶积分 = 初阶基础分 × `tier_config` 倍率（进阶=2）。系统已自动处理，出题无需关心。

---

## 2. 思路模式（与初阶一致，写在 `explanation` 字段）

- 初阶的「思路」就写在 **`explanation`** 字段里（例：「先设 i=1，循环条件 while i<=5，每次打印后 i+=1。」），**没有独立思路字段**。
- 进阶沿用同一字段、同一写法：**`explanation` = 思路拆解 + 讲解**，用自然语言写清「怎么想 / 分几步 / 注意什么」。
- **不要新增 `approach` 字段**——初阶没有，进阶也不该有，机制须一致。
- 推荐写法（与初阶同风格，因题更难可略展开）：
  - **思路**：先做什么、再做什么、用到哪些知识点（可点名前面课的知识）；
  - **讲解**：关键语法 / 易错点（如变量名不加引号、循环别漏 `i+=1`、函数要 `return` 才拿到值）。

---

## 3. 评分机制（与初阶完全一致：纯 LLM ai评分）

- 调用链路：`routers/exam.py` → `core/llm_grader.grade_code(题干, expected_output, 学员代码, 运行结果)`。
- 初阶 400 道 code 题 **`expected_output` 全部为 `null`**，评分完全由 LLM 完成：
  - 沙箱实跑学员代码得到 `运行结果`；
  - LLM 依据「题目要求 + 运行结果」给 **星级(0–5) + 分数(0–100) + 反馈**；
  - `expected_output` 为空时 LLM 自动用「(无预设期望输出)」判断，**不比对输出**。
- LLM 系统提示词已规定：**先肯定做得好的地方，再温和指出可以改进的地方**（不用「你错了」），天然满足「LLM 指出学员错处和改进方式」。
- **进阶必须保持一致**：`expected_output` 留空，不擅自加输出比对。
  - （可选）若题目输出确定唯一，可填 `expected_output` 作为 LLM 参考；但 LLM 仍是终评，不改变「机制一致」原则。一般不建议填，保持与初阶同态。

## 4. 命题模板（每道进阶题字段清单）

直接可填的 JSON，用于批量导入 `POST /api/questions/batch`：

```json
{
  "subject_id": 3,
  "topic_id": 51,
  "type": "code",
  "tier": 2,
  "difficulty": 2,
  "content": "（完整小程序题目：输入→处理→输出，综合本课及前面课知识；L1–L4 目标 ~10–15 行、L5+ 目标 20–50 行，行数仅为出题体目标）",
  "sample_input": "<用到 input() 时必填，如 \"3\\n5\\n2\\n\">",
  "expected_output": null,
  "explanation": "思路：先……再……用到 课X 的……\n讲解：关键语法/易错点……",
  "options": null,
  "is_multiple": false,
  "deprecated": false
}
```

> ⚠️ **sample_input 必填规则（踩坑后修正）**：参考解用到 `input()` 的题，**必须**填 `sample_input`；纯 print 题才留 `null`。留空会导致评分沙箱无 stdin、`input()` 抛 EOFError、运行报错、LLM 给 0 分。初阶 400 题 `sample_input` 全空，且其中 17 道 input 类题同样存在此隐性问题——进阶题应**做对**，不要照搬这个缺陷。

## 5. 代码量规范（目标体量，非评分标准）

> ⚠️ 行数是**出题目标**，不是评分依据。下面所有行数描述的是「我们设计题时希望孩子写出的体量」，用于倒逼题目足够综合、练得到编码；**绝不把行数写进 LLM 评分**。

- 目标参考解体量：**20–50 行** Python（L5 及以后很自然能达到）。
- 进阶的目的就是「编码练习」，所以进阶题天然要比初阶（初阶参考解通常 3–5 行）**明显更长**，否则达不到练手目的——哪怕早期基础课，也不能缩回三两行。
- 不是「三两行」：要有真实的**输入处理 → 循环/判断/函数 → 聚合 → 格式化输出**链路。
- 题目本身要能让孩子写出足够长的程序；过短说明没综合够知识，需加条件 / 分支 / 循环 / 多步聚合 / 输入校验。
- **配套必做**：只要参考解用到 `input()`，就必须同时填 `sample_input`（见 §1 / §4 模板）。否则评分沙箱无输入可喂，代码运行即报错、该题永远 0 分。这是进阶题上线前必须自检的一项。

### 5.1 早期基础课（L1–L4）的折中

L1 变量/print、L2 注释输出、L3 格式化、L4 运算符/输入 这些课，单点知识确实很薄，硬凑 20 行会很生硬。处理办法：

- **不设 20 行硬下限**，但设**软下限 ~10 行**：必须明显长于初阶（初阶 3–5 行），要包含「输入 → 处理 → 多情况输出」的完整小程序，而不能一句话打印；
- 用「 realistic 场景 + 多分支/多变量/格式化」撑长度：比如 L1 进阶「输入姓名和出生年，输出自我介绍并计算到 80 岁还有多少年」，约 12 行；
- L5 以后回到 20–50 行目标。

> 原则：早期课允许 10–15 行（软下限，不是硬卡），但绝不能回到初阶那种三两行；L5+ 一律按 20–50 行目标出。

## 9. 样例（L1–L20 各 2 道，含可跑通参考解）

> 以下 8 道为**早期基础课**的示范，参考解均已在本地 python 跑通（8/8）。L1/L2 的 Q1、L4 的 Q1 贴近软下限上限（~8–10 行）；L2/L3/L4 的 Q2 因单点知识薄，参考解约 5–7 行，属软下限下限——但都是**完整小程序**，绝非三两行。L5+ 一律按 20–50 行目标出（见 §6 各课范围）。
> 每道均 `tier=2`、`expected_output=null`、`explanation` 含「思路+讲解」。

### L1（topic 45：变量命名/赋值/print）

**Q1 自我介绍 + 80 岁目标**
- content：输入你的姓名和出生年份（如 `小明 2012`，中间空格分开）。先输出一行 `我叫小明，今年 X 岁`；再输出一行 `到 80 岁还有 Y 年`（Y = 80 − 今年年龄，今年按 2026 算）。若已年满 80，改输出 `已经达成 80 岁目标`。
- explanation：思路：用 `input().split()` 一次读出姓名和年份，年份 `int()` 转整数；用 `2026 - year` 算年龄；`if age < 80` 分两种情况打印。讲解：split 默认按空格切；字符串和数字不能直接算，年份必须 `int()`；判断用 `<` 不要漏等号边界。
- 参考解（约 8 行）：
```python
name, year = input().split()      # 读姓名和出生年
year = int(year)
age = 2026 - year
print(f"我叫{name}，今年 {age} 岁")
if age < 80:
    print(f"到 80 岁还有 {80 - age} 年")
else:
    print("已经达成 80 岁目标")
```

**Q2 三门成绩统计**
- content：输入三门课成绩（语文、数学、英语，空格分开，如 `90 85 95`）。先输出总分，再输出平均分（保留 1 位小数），最后判断：平均分 ≥ 60 输出 `及格`，否则 `不及格`。
- explanation：思路：`map(int, input().split())` 一次转三个整数；求和得总分，除以 3 得平均分；用 `if avg >= 60` 判及格。讲解：`map` 可一次把多个输入转 int；平均分要浮点除（直接 `/3` 即可）；保留小数用 `:.1f`。
- 参考解（约 8 行）：
```python
a, b, c = map(int, input().split())   # 语数英
total = a + b + c
avg = total / 3
print(f"总分：{total}")
print(f"平均分：{avg:.1f}")
if avg >= 60:
    print("及格")
else:
    print("不及格")
```

### L2（topic 46：注释 #、print 多参数、sep / end）

**Q1 用 end 连成一行**
- content：用 `for` 循环依次处理数字 1 到 5，要求用 `print` 的 `end` 参数让它们以逗号连接显示在同一行（`1,2,3,4,5`），循环结束后换行并再打印 `完成`。
- explanation：思路：循环 `range(1,6)`；前四个数字用 `print(i, end=",")` 不换行加逗号，最后一个用 `end=""` 收尾；循环后 `print()` 补换行，再打印 `完成`。讲解：`end` 决定 print 结尾字符，默认是换行 `\n`；想连成一行就改 `end`；记得最后补一个空 `print()` 换行。
- 参考解（约 8 行，含注释）：
```python
# L2：print 的 end 参数控制结尾字符
for i in range(1, 6):
    if i < 5:
        print(i, end=",")     # 前四个逗号连接
    else:
        print(i, end="")      # 最后一个不换行
print()                       # 补换行
print("完成")
```

**Q2 用 sep 与 end 排版**
- content：输入三种水果名（一行空格分开，如 `苹果 香蕉 橙子`），先用 `sep` 以 ` / ` 连接打印成 `苹果 / 香蕉 / 橙子`；再在同一行接着打印 `今日共 N 种水果`（N 为水果个数）。
- explanation：思路：`input().split()` 得到水果列表；`print(*fruits, sep=" / ")` 用星号展开列表并以斜杠分隔；再用两次 `print(..., end="")` 把「今日共 N 种水果」接到同一行。讲解：`*列表` 把元素当多个参数传给 print；`sep` 是参数间分隔符，`end` 是整体结尾符；计数用 `len(fruits)`。
- 参考解（约 7 行，含注释）：
```python
# 用 sep 指定元素间的分隔符
fruits = input().split()
print(*fruits, sep=" / ")     # 苹果 / 香蕉 / 橙子
# 用 end 在同一行追加内容
print("今日共", end="")
print(len(fruits), end="")
print(" 种水果")
```

### L3（topic 47：int / float / str、f-string、format）

**Q1 圆的半径周长面积**
- content：输入一个圆的半径（可为小数），输出半径、周长（保留 2 位小数）、面积（保留 2 位小数），均用 f-string 格式化。
- explanation：思路：`float(input())` 读半径；用 `math.pi` 算 `周长=2πr`、`面积=πr²`；f-string 里用 `:.2f` 保留两位。讲解：圆周率用 `math.pi` 更准；半径可能带小数要 `float()`；`**` 或 `r*r` 求平方；格式化小数用 `:.2f`。
- 参考解（约 7 行）：
```python
import math
r = float(input())
c = 2 * math.pi * r
s = math.pi * r * r
print(f"半径：{r}")
print(f"周长：{c:.2f}")
print(f"面积：{s:.2f}")
```

**Q2 format 明年与百岁**
- content：输入姓名和年龄（一行空格分开，如 `小明 12`）。输出 `你好，小明，你明年13岁`；再输出 `距离 100 岁还有 88 年`；再输出 `小明 还需 7 轮生肖到百岁`（每 12 年一轮）。
- explanation：思路：`input().split()` 拆姓名年龄，年龄 `int()`；用 `str.format` 拼接明年年龄、距百岁年数、生肖轮数（整除 12）。讲解：`.format()` 用 `{}` 占位，按顺序填；年龄运算要先 `int()`；`//` 是整数除得轮数。
- 参考解（约 6 行）：
```python
name, age = input().split()
age = int(age)
print("你好，{}，你明年{}岁".format(name, age + 1))
print("距离 100 岁还有 {} 年".format(100 - age))
print("{} 还需 {} 轮生肖到百岁".format(name, (100 - age) // 12))
```

### L4（topic 48：运算符、input()、转义 \n \t）

**Q1 两数四则 + 整除判断**
- content：输入两个整数 a、b（空格分开，如 `17 5`）。依次输出：和、差、积；若 b 不为 0，再输出余，并判断 `整除` 或 `不整除`；若 b 为 0，输出 `除数不能为 0`。
- explanation：思路：`map(int, input().split())` 读两数；直接算和差积；用 `if b != 0` 防零除，再算余并用 `a % b == 0` 判整除。讲解：余数用 `%`；除零会报错，必须先判断 `b != 0`；`整除` 等价于余数为 0。
- 参考解（约 9 行）：
```python
a, b = map(int, input().split())
print(f"和：{a + b}")
print(f"差：{a - b}")
print(f"积：{a * b}")
if b != 0:
    print(f"余：{a % b}")
    print("整除" if a % b == 0 else "不整除")
else:
    print("除数不能为 0")
```

**Q2 转义字符排版**
- content：输入一行文字（如 `你好`）。原样输出一次；再用转义字符分别输出：①带双引号的 `“你好”` ②带单引号的 `‘你好’` ③带换行的（`第一行` 后换行再显示输入内容）。
- explanation：思路：用 `\"` 转义双引号、`\'` 转义单引号、`\n` 转义换行，配合 `.format()` 把输入内容嵌进去。讲解：字符串里想显示引号本身要用反斜杠转义，否则会和字符串边界冲突；`\n` 是换行符；单双引号转义按字符串外层引号选择即可。
- 参考解（约 5 行，含注释）：
```python
s = input()
print("原始：", s)
print("加双引号：\"{}\"".format(s))   # 转义双引号
print('加单引号：\'{}\''.format(s))   # 转义单引号
print("换行效果：\n{}".format(s))      # 转义换行
```

### L9（topic 53：列表的定义与增删改查,列表推导式）

**Q1**

def timer(func):

    def wrapper(*args, **kwargs):

- **思路**：思路：① retry(times) 是『装饰器工厂』：外层接收参数 times，返回真正装饰器 deco，再返回 wrapper——三层闭包；② wrapper 用 for 循环重试，range(times+1) 含首次共 times+1 次；③ except Exception 捕获后判断是否还能重试，不能则重新 raise；④ @retry(3) 语法糖演示参数化装饰器；综合展示『闭包 + 参数化装饰器 + 异常再抛出』。

- **参考解（约 28 行）**：
```python
from functools import wraps

def retry(times):
    def deco(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            for attempt in range(times + 1):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    if attempt < times:
                        print(f'  {func.__name__} 第{attempt+1}次重试（原因：{e}）')
                    else:
                        print(f'  {func.__name__} 重试{times}次仍失败：{e}')
                        raise
        return wrapper
    return deco

@retry(3)
def may_fail(x):
    if x <= 0:
        raise ValueError('x 必须为正')
    return x * 2

print('测试 x=5（应一次成功）：')
print('  结果 =', may_fail(5))
print('测试 x=-1（应重试3次后抛错）：')
try:
    may_fail(-1)
except ValueError as e:
    print(f'  最终捕获：{e}')
```

- **题面**：缓存装饰器。实现装饰器 `cache(func)`，用字典保存『参数->结果』：被装饰函数调用前先查缓存，命中则打印『命中缓存』并直接返回，否则计算并存入。  
将 @cache 应用于递归斐波那契 `fib(n)`（返回 fib(n)）以演示记忆化避免重复计算；主程序计算 fib(20) 并输出，再重复计算 fib(20) 演示缓存命中，最后打印缓存条目数。
- **思路**：思路：① cache 内部用闭包变量 store 字典缓存结果，args 作为键；② 命中时直接返回避免重复计算，否则算完存入——这就是记忆化（memoization）；③ 应用在递归 fib 上，把指数级重复调用降到线性；④ wrapper.cache_info 暴露缓存状态；⑤ @cache 语法糖让『递归函数 + 自动缓存』一行搞定，体现标准装饰器的工程价值。
- **sample_input**：（纯 print，无 input）
- **参考解（约 21 行）**：
```python
from functools import wraps

def cache(func):
    store = {}
    @wraps(func)
    def wrapper(*args):
        if args in store:
            print(f'  命中缓存 {func.__name__}{args}')
            return store[args]
        result = func(*args)
        store[args] = result
        return result
    wrapper.cache_info = lambda: len(store)
    return wrapper

@cache
def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

print('首次计算 fib(20)：', fib(20))
print('再次计算 fib(20)（应命中缓存）：', fib(20))
print('缓存条目数：', fib.cache_info())
```
