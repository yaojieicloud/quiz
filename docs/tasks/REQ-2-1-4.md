## 实现要点

### CSS 样式

三种卡片样式：
- `.delta-card.mastered` - 金色渐变背景（新达到精通）
- `.delta-card.up` - 绿色渐变背景（精通度提升）
- `.delta-card.same` - 灰色背景（未提升）

### renderMasteryDelta(d)

根据 `d.newly_mastered` / `d.delta` / `d.bottleneck` 渲染不同卡片：

| 条件 | 卡片 | 文案 |
|------|------|------|
| newly_mastered=true | 🎉 金色 | "恭喜！已精通！" |
| delta>0 | 📈 绿色 | "精通度 +X%！继续加油！" |
| delta=0, bottleneck=rate | 💪 灰色 | "正确率还不够，争取答对更多！" |
| delta=0, bottleneck=coverage | 💪 灰色 | "做过的题型还不够多样，试试更多不同的题！" |
| delta=0, bottleneck=count | 💪 灰色 | "做得还太少，再多练几次！" |

### showResult 调用

在积分横幅下方、全对提示上方插入精通度变化区域。
