> 需求: REQ-2 答题后精通度变化展示
> 状态: ✅已完成

## 任务描述

在 `src/routers/exam.py` 的 `submit_exam` 函数中：

1. 在 upsert 精通度前，快照当前学员在各课程的精通度状态
2. upsert 后，对比新旧精通度，计算 delta
3. 如果精通度未提升（delta == 0），调用瓶颈诊断函数
4. 将 mastery_deltas 传递给 `_record_to_out`

## 实现要点

### 快照逻辑

在 upsert 前查询当前精通度状态：
```python
prev_mastery = {}
for mastery in db.query(StudentMastery).filter(...).all():
    prev_mastery[mastery.topic_id] = {
        'rate': mastery.rate,
        'coverage': mastery.coverage,
        'N': mastery.answered_count,
        'Q': mastery.topic_total
    }
```

### Delta 计算

对每个涉及的 topic，计算精通度变化：
```python
before_pct = calc_mastery_pct(prev_status, prev_rate, prev_cov, prev_N, prev_Q)
after_pct = calc_mastery_pct(status, rate, coverage, N, Q)
delta = after_pct - before_pct
```

### 瓶颈诊断

如果 delta == 0 且未新达精通，诊断瓶颈：
```python
if delta == 0 and not newly_mastered:
    bottleneck = diagnose_bottleneck(rate, coverage, N, Q)
```

### 响应传递

修改 `_record_to_out` 签名，新增 `mastery_deltas` 参数。
