> 需求: REQ-2 答题后精通度变化展示

## 任务描述

在 `src/core/mastery.py` 中新增两个工具函数：

1. `calc_mastery_pct(status, rate, coverage, N, Q)` - 计算精通度百分比
2. `diagnose_bottleneck(rate, coverage, N, Q)` - 诊断未提升的瓶颈原因

## 实现要点

### calc_mastery_pct

- status == 'mastered' → 100
- 否则取 min(R/90%, Ccov/80%, N/threshold) × 100，封顶 99
- 无答题 → 0

### diagnose_bottleneck

- 计算正确率缺口、覆盖度缺口、做题数缺口
- 返回差距最大的一项作为瓶颈（rate/coverage/count）
- 全部达标返回 None
