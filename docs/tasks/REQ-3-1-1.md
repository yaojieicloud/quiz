## 验收记录（2026-08-29，只读实测，本地 data/quiz.db 学员「尧奕瑶」tier=1）

| 科目 | 结果 |
|------|------|
| Python基础理论（20 课，sort_order 0-19） | ✅ 递进生效：第 1 课解锁，其余 19 课锁定；默认选中「变量与标识符」 |

| 数学（13 课，sort_order 0-12） | ✅ 递进生效：第 1 课解锁、其余锁定，默认选中「时、分、秒」 |
| 语文（69 课）/ 英语（48 课） | ⚠️ 全部解锁：**数据问题**——两科 topics 的 `sort_order` 全为 0（批数据时未填排序），无"前序课"故无递进约束；算法本身正确，需补排序数据后生效 |

已知限制（不阻塞验收）：
- 语文/英语 `sort_order` 全 0 → 递进对两科暂不生效，后续补排序数据即自动生效，无需改代码。
- 后端校验按 `(topic_id, tier)` 查 `student_mastery`，与前端同口径，一致。
