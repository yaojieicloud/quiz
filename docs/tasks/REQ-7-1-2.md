# REQ-7-1-2 管理端：admin.html 课程编辑弹窗加两 URL 字段

## 1. 任务描述

管理端 `admin.html` 的 `openTopicModal` 弹窗在排序字段后追加两个 URL 输入框（B站视频 + 在线课本）。`saveTopic` 函数 POST/PUT body 加两字段。

## 2. 涉及文件

- `src/static/admin.html`

## 3. 实施步骤

### 3.1 修改 `openTopicModal`（line 756-771）

在 `.form-group`「排序」后插入两个 `.form-group`：

```javascript
<div class="form-group">
  <label>📺 B站视频嵌入 URL</label>
  <input type="url" class="form-input" id="fTopicVideoUrl"
    value="${t ? esc(t.tutorial_video_url || '') : ''}"
    placeholder="如：https://player.bilibili.com/player.html?bvid=BV1xxxxxxx">
</div>
<div class="form-group">
  <label>📖 在线课本 URL</label>
  <input type="url" class="form-input" id="fTopicBookUrl"
    value="${t ? esc(t.tutorial_book_url || '') : ''}"
    placeholder="如：https://book.pep.com.cn/1212001401255/mobile/index.html">
</div>
```

### 3.2 修改 `saveTopic`（line 773-）

```javascript
// 收集 URL 字段（line 778 区域，unit 之后）
const videoUrlEl = document.getElementById('fTopicVideoUrl');
const bookUrlEl  = document.getElementById('fTopicBookUrl');
const tutorial_video_url = videoUrlEl ? (videoUrlEl.value.trim() || null) : null;
const tutorial_book_url  = bookUrlEl  ? (bookUrlEl.value.trim()  || null) : null;
```

PUT body 改：
```javascript
const updated = await API.put('/api/topics/'+topicId, {
  name, unit, sort_order: order,
  tutorial_video_url, tutorial_book_url
});
```

POST body 改（找到 create_topic 路径，body 加同两字段）：
```javascript
const created = await API.post('/api/topics', {
  subject_id, name, unit,
  tutorial_video_url, tutorial_book_url
});
```

### 3.3 课程行展示

在 `topicsCache` 同步逻辑（line 783-808）里，把新两字段也合并进 cache（**最小改动**：直接用 `{ ...list[i], ...updated }` 已含全部新字段，无需额外处理）。
