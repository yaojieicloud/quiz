# BUG-3：实操每次 count=1 时连续抽到同一题

- **类型**：抽题逻辑缺陷
- **严重度**：高（学员体验差，同一题反复出现）
- **状态**：✅ 已修复（2026-08-29）
- **来源**：覃禹诺（学员 id=4）反馈

## 问题描述

覃禹诺做 Python 基础实操时，做错一题后系统连续抽同一题，做了 6-7 次才换题。

**数据佐证**（2026-08-29）：
| record_id | question_id | 结果 |
|-----------|-------------|------|
| 580 | 2105 | 错 |
| 581 | 2105 | 错 |
| 582 | 2105 | 对 |
| 583 | 2105 | 对 |
| 584 | 2105 | 对 |
| 585 | 2105 | 对 |
| 586 | 2105 | 对 |

连续 7 次抽到 qid=2105（同一道"变量与标识符"编程题）。

## 根因

`routers/exam.py:_rank_pool` 抽题排序逻辑：

```python
# 旧代码
layer2.sort(key=lambda q: (-wrong.get(q.id, 0), cnt.get(q.id, 0)))
```

- 错题层（layer2）排序只用 `(-错次, 做题次数)`
- 实操每次 count=1，错次最多的题永远排第一
- 没有去重/冷却机制，刚做过的题下一轮仍可能被抽中

## 修复方案

`_rank_pool` 增加两个机制：

1. **冷却机制**：查该学员最近一次考试的 question_ids，在 layer2 中强制排最后
   - 刚做过的题不会在下次抽到
2. **时间打散**：layer2 排序增加最近答题时间（最久没做的优先）

```python
# 新代码
layer2.sort(key=lambda q: (
    q.id in cooldown_qids,            # 冷却题排最后
    -wrong.get(q.id, 0),              # 错次降序
    cnt.get(q.id, 0),                 # 做题次数升序
    last_done.get(q.id, epoch),       # 最近答题时间升序
))
```

## 已知行为（非 bug）

答题页内刷新/重进仍显示同一题 — 这是 localStorage 缓存设计，防止答题中途丢题。只有提交后冷却机制才生效（`exam_records` 落库）。学员正常退出→重新进入→重新抽题，不会再连续重复。
