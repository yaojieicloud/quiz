# 组卷与答题流程 设计文档

> 模块：`routers/exam.py`、`static/home.html`、`static/quiz.html`
> 关联：[题型与出题规范](题型与出题规范.md)、[积分与奖励体系](积分与奖励体系.md)

---

## 1. 组卷（POST /api/exam/start）

入口在 **home.html**（非 quiz.html）：选科目→章节/题型/题数/模式，结果写 `localStorage['quiz_exam']` 后跳 `quiz.html`。

- 题数白名单：**`(1, 10, 20, 50)`**（`exam.py:314`），否则 400「题目数量只能选择 1、10、20、50 题」。前端档位 chip 仅 10/20/50，默认 文化类=50 / 编程理论=10（`home.html`）。
- 不落库、未交卷不产生空记录（`exam.py:316`）。
- 排除弃用题：`deprecated IS NULL OR = False`（`exam.py:319`）。
- `mode=wrong` 走错题池（未 mastered），同样受科目 `allowed_types` 约束（`exam.py:329-330`）。
- 题型过滤：请求 `types` ∩ 科目 `allowed_types`，交集空返回空题目（`exam.py:337-340`）。
- `random.shuffle(pool)` 取前 count（`exam.py:351-352`）。
- **防泄题**：reading 子题剥离 answer/explanation（`exam.py:359-363`）；code 题下发 explanation 但 `answer` 置 None（`exam.py:301-302`）。

---

## 2. 答题

- 试跑代码：`POST /api/exam/run-code`（`exam.py:590-600`，`quiz.html:976`）仅实跑、不判分不落库。
- 答题交互在 `quiz.html`，9 种题型共用 `common.js#renderAnswerCard` 渲染。

---

## 3. 交卷（POST /api/exam/submit）

入参 `{subject_id, mode, topic_ids, answers:[{question_id,user_answer}], duration_seconds}`（`exam.py:434-500`）。
- 校验 answers 非空 + question_id 全部存在（否则 400）。
- `started_at = now - duration_seconds`（`exam.py:449`，时长从前端上报还原）。
- 逐题 `_judge` 判分，写 `AnswerRecord`（is_correct / llm_score / llm_stars / llm_feedback / run_output）。
- 总分 `score = int(correct / total * 100)`（`exam.py:493`）。
- 错题入本：答错且 `ar_score < 60` → upsert `wrong_questions`（wrong_count++）。
- 返回 `ExamRecordOut`（含 `points_earned`）。
- 历史积分从 `points_ledger` 回填（`exam.py:521-526`）。

> ⚠️ 已知落差：`submit_exam` 未传入 `data.mode`（错题重做也落成 `custom`）；`topic_ids` 未持久化；`AnswerRecord.time_used` 恒为 0。

---

## 4. 积分发放 `_award_exam_points`（`exam.py:385-430`）

与成绩**同一事务** `db.commit()`：
1. 优先 `subject_points` 覆盖：≥100→p100，≥90→p90，≥80→p80，否则 0。
2. 无覆盖走 `scoring_rules`：`score_band <= record.score AND is_active` 取 `score_band` 最大者。
3. **<80 分一律 0**；`pts<=0` 直接 return 0，不写流水。
4. 写 `PointsLedger(reason="exam_reward", ref_id=record.id, balance_after=...)`。

默认档位：`100→5 / 90→4 / 80→3`（见 [积分与奖励体系](积分与奖励体系.md)）。

---

## 5. 记录查询

- `GET /api/exam/records`（列表，不含明细）
- `GET /api/exam/records/{id}`（含每题明细）
- `GET /api/wrong-questions`、`POST /api/wrong-questions/{id}/master`、`DELETE /api/wrong-questions/{id}`（错题本标掌握/删除）

前端：`records.html`（学员记录+明细）、`wrong.html`（错题本）。

---

## 6. 相关前端

- `home.html`：组卷入口、选课单题。
- `quiz.html`：答题主界面、试跑代码、交卷。
- `records.html` / `wrong.html`：记录与错题。
