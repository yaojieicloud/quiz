## 2. 本地 Docker（`quiz-local`）

```bash
docker build -t quiz-system:local -f src/Dockerfile src
mkdir -p data   # ★ 数据库唯一合法路径 = data/quiz.db；文件不存在则容器启动自动建库（不再从 src/ 复制）
docker run -d --name quiz-local -p 8000:8000 \
  -v "$(pwd)/data:/app/data" --restart unless-stopped quiz-system:local
```

`entrypoint.sh`：先跑数据库迁移（保证 `scoring_rules.subject_id`、`mastery_rewards` 等新列就位），再 `python seed_reward.py`（幂等播种积分/转盘/直兑），最后 `exec uvicorn main:app --host 0.0.0.0 --port 8000`。顺序关键：种子依赖迁移新增的列，必须先迁移后播种。日志 `docker logs -f quiz-local`；重启 `docker restart quiz-local`。

## 3. ECS 部署与热更新

ECS 为 Alibaba Cloud Linux 3，已配置阿里云 pip 源（`mirrors.aliyun.com`），走 `docker build` 标准部署。

### 3.1 ECS 实际目录结构

```
/opt/quiz-system/
├── docker-compose.yml    # 仅 image: quiz-system:latest 引用（无 build 段）
├── build/                # 实际运行源码（与本地仓库 src/ 对应）
│   ├── Dockerfile
│   └── main.py / models.py / schemas.py / routers/ / core/ / static/ ...
└── data/            # DB 数据卷（quiz.db + backups/ + 密钥）
```

> ⚠️ 本地 `src/` 即对应 ECS 的 `build/`；本地改代码后需 scp 到 `build/` 再重建镜像才生效。
> ⚠️ 历史坑：ECS `build/core/` 曾缺失 `tier.py`、`schemas.py` 也曾与本地不同步，导致重建后 import 失败、容器重启循环。**每次部署前务必确认 `build/` 与本地 `src/` 完整一致**（缺文件/旧文件都会致启动失败）。

### 3.2 ECS SSH 连接信息

| 项目 | 值 |
|------|-----|
| **IP** | `106.14.99.100` |
| **SSH 端口** | `22` |
| **用户名** | `root` |
| **认证方式** | 公钥（私钥路径：项目根目录 `openclaw.pem`） |
| **部署目录** | `/opt/quiz-system/` |
| **Docker 镜像** | `quiz-system:latest` |

> **重要**：ECS 已禁用密码认证，必须使用私钥连接。`openclaw.pem` 在项目根目录，不可删除。

### 3.3 重建镜像标准流程

```bash
# 1. scp 改动文件到 build/
scp -i openclaw.pem src/xxx.py root@106.14.99.100:/opt/quiz-system/build/xxx.py
# 2. 打回滚标签
docker tag quiz-system:latest quiz-system:rollback-<ts>
# 3. 重建镜像（pip 层有缓存，快）
ssh -i openclaw.pem root@106.14.99.100 "cd /opt/quiz-system/build && docker build -t quiz-system:latest -f Dockerfile ."
# 4. 重启容器
ssh -i openclaw.pem root@106.14.99.100 "cd /opt/quiz-system && docker compose up -d"
# 5. 健康检查
curl -o /dev/null -w '%{http_code}\n' http://106.14.99.100:8000/
```

> DB 在数据卷 `data`，重建镜像不丢数据。回滚：`docker tag quiz-system:rollback-<ts> quiz-system:latest && docker compose up -d`。

### 3.4 应急热更新（`docker cp`）

1. 本地打包：`tar --exclude='*.db' --exclude='__pycache__' --exclude='data' -czf quiz-src.tar.gz -C src .`
2. `scp -i openclaw.pem quiz-src.tar.gz root@106.14.99.100:/opt/quiz-system/`
3. `ssh -i openclaw.pem root@106.14.99.100 "cd /opt/quiz-system && tar -xzf quiz-src.tar.gz -C /tmp/quiz-build && docker cp /tmp/quiz-build/. quiz-system:/app/ && rm -rf /tmp/quiz-build"`
4. `ssh -i openclaw.pem root@106.14.99.100 "docker exec quiz-system python seed_reward.py"`（可选）
5. 写密钥（如需要）：`ssh -i openclaw.pem root@106.14.99.100 "printf '%s\n' '<KEY>' > /opt/quiz-system/data/deepseek_key.txt"`
6. `ssh -i openclaw.pem root@106.14.99.100 "docker restart quiz-system"`（改 .py 才需 restart）

> 静态文件（html/js/css）`docker cp` 即生效；改 `.py` 才需 restart。ECS 也可走运维 API（见 §5）。
> **Schema 变更不要手敲 `ALTER`**：新增字段一律走迁移文件，见 [数据库迁移机制](数据库迁移机制.md)。应用启动时 `run_migrations()` 自动为已存在的库补齐增量字段。

## 4. 拉取线上库到本地

```bash
.venv/Scripts/python.exe scripts/fetch_db.py
```

- `BASE_URL = "http://106.14.99.100:8000"`（`fetch_db.py:10`），`admin/admin123` 登录（`fetch_db.py:18`）。
- 走 `POST /api/admin/exec-sql` 读 `sqlite_master` / `PRAGMA table_info`，每批 `LIMIT 500` 在本地 sqlite3 重建。
- 旧库自动改名 `data/quiz.db.old`。**纯 API，不碰容器**。目标库为 `../../data/quiz.db`（数据库唯一合法路径）。

## 5. 运维 API（前缀 `/api/admin`，全部 `require_role("admin")`）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/exec-sql` | 先自动 `VACUUM INTO` 备份再执行；SELECT/PRAGMA/WITH/EXPLAIN 返回行，DML 返回影响行数；`script:true` 走多语句 |
| POST | `/update-file` | 写 `/app` 内文件（path 越权 400），自动建父目录 |
| POST | `/pip-install` | 容器内 pip install（包名含危险字符拒绝，timeout 120s） |
| POST | `/restart` | 子线程 sleep 1s 后 `os._exit(0)`，依赖 compose `restart: always` 自动重启 |
| POST | `/backup-db` | `VACUUM INTO` 原子备份，返回 name/path/size |
| GET | `/backup-db` | 列出备份（name/size/mtime） |
| GET | `/backup-db/download?name=` | 下载（防目录穿越，拒 `/ \ ..`；用 `Response` 而非 `FileResponse` 规避 Docker 卷 sendfile 0 字节坑） |
| POST | `/re-grade` | 历史 code 题 LLM 重评并重算 exam_records |

**写操作前务必先备份**：`POST /api/admin/backup-db`。

## 6. 安全与密钥

- `QUIZ_SECRET_KEY`（默认 `quiz-system-secret-key-change-in-production-2024`）、`QUIZ_REGKEY=openschool2026`、aliyun/deepseek key 一律走环境变量或数据卷文件，**禁止写入代码或提交仓库**（`.gitignore` 已排除 `data/`、`*.db`、`.venv`）。
- 备份落点：与 DB 同处数据卷 `./data -> /app/data/backups`，随卷持久化、随容器重启不丢。
