## 1. 数据模型

### users（`models.py:12-28`）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | Integer PK | — |
| username | String(50) unique | 登录名 |
| nickname | String(50) | 昵称（显示在记录/核销处，优先于 username） |
| password_hash | String(255) | pbkdf2_sha256 哈希 |
| role | String(20) | `student` / `parent` / `admin`（`schemas.py` 正则强校验） |
| bind_code | String(20) unique, 可空 | 学生注册时生成，家长输入后绑定 |
| created_at | DateTime | — |

### parent_child（`models.py:31-42`）
`id / parent_id(FK users.id) / child_id(FK users.id) / created_at`，唯一约束 `(parent_id, child_id)`。
> User 侧两个 FK 都指向 users，故 `parent_links`/`child_links` 必须显式声明 `foreign_keys`（`models.py:27-28`）。

## 2. 鉴权机制

- **JWT**：`OAuth2PasswordBearer(tokenUrl="/api/auth/login", auto_error=False)`，即 `Authorization: Bearer <token>`（`deps.py:11`）。
- payload：`{"sub": str(user.id), "role": ...}`（`security.py:20-25`）。
- `get_current_user` **只用 sub 查库、role 取自 DB** 而非 token（`deps.py:22-27`）→ 改角色即时生效。
- `require_role(*roles)` 工厂：`user.role not in roles` → 403（`deps.py:31-37`）。
- 哈希：pbkdf2_sha256（纯 Python，免编译）（`security.py:9`）。

## 3. 接口清单（前缀 `/api/auth`）

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/register?regkey=` | 公开（需密钥） | 注册；body 含 username/nickname/password/role；失败 403 |
| POST | `/login` | 公开 | 返回 `access_token` |
| GET | `/me` | 登录 | 当前用户信息 |
| POST | `/bind-child` | parent | 用 `bind_code` 绑定孩子（非 parent 即 403） |
| GET | `/children` | parent | 已绑定孩子列表 |

注册校验：`REGKEY = os.getenv("QUIZ_REGKEY", "openschool2026")`，`secrets.compare_digest` 防时序攻击（`auth.py:16,22`）。绑定码 `secrets.token_hex(3).upper()` = 6 位大写十六进制，仅 student 生成（`deps.py:42`、`auth.py:31`）。

## 4. 家长端（前缀 `/api/parent`）

全部经 `_check_child`（`parent.py:15-24`）三重校验：角色=parent、存在 `parent_child` 绑定、child 存在且 role=student。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/children/{child_id}/records` | 孩子答题记录 |
| GET | `/children/{child_id}/wrong` | 孩子错题本 |
| GET | `/children/{child_id}/stats` | 复用 `stats.overview(user=child)` |

前端 `parent.html`：非 parent 直接拦截；先 bind 绑娃，再查看孩子概览/记录。

---

## 5. 设计要点与缺口

- 同源部署静态资源，`main.py` **无 CORS 中间件**。
- **无**改密/删号/改角色接口；admin 账号（`admin/admin123`）为手工/脚本注册，非启动保证（见 `fetch_db.py:18` 客户端凭据）。
- 注册未开放（需 regkey），无小号刷分风险。
