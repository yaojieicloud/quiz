# 题型与出题规范 设计文档

> 模块：题型判定在 `routers/exam.py` 的 `_judge*` 系列；题型常量见 `models.py`；出题模板见 `data/template/`
> 关联：[科目与知识点体系](科目与知识点体系.md)、[组卷与答题流程](组卷与答题流程.md)

---

## 1. 题型体系（9 种）

| 题型 | type | 适用科目 | 判分方式 |
|---|---|---|---|
| 选择题 | `choice` | 全部 | 归一化后字符串相等；多选需全对 |
| 判断题 | `judge` | 全部 | 固定选项 `["对","错"]`，同 choice |
| 计算题 | `calc` | 数学/Python理论 | 文本答案，支持数字容差 |
| 填空题 | `fill` | 文化类 | 单空/多空，支持数字容差 |
| 应用题 | `essay` | 数学 | 无标准答案（见 §3 降级） |
| 连线题 | `match` | 文化类 | 左右配对（顺序无关） |
| 排序题 | `sort` | 文化类 | 顺序索引串全等 |
| 阅读理解 | `reading` | 仅语文/英语 | 一篇文章 + 多子题，按比例给分 |
| 编程题 | `code` | Python实操 | 沙箱实跑 + LLM 评星（见 [AI 评分](AI评分与学情报告.md)） |

---

## 2. 统一评分字段

所有题型统一产出 `{stars(0-5), score(0-100), feedback}`，写入 `AnswerRecord.llm_score` / `llm_stars` / `llm_feedback`（`exam.py:31-64`）。**`llm_score` 是唯一评分字段**，正确与否统一以 `ar_score >= 60` 判定。

### 归一化 `_normalize`（`exam.py:21-28`）
去空格（含全角）、全角标点转半角、转小写——选择题/判断题比对前必经。

### 各题型判法
| 题型 | 逻辑 | 行号 |
|---|---|---|
| choice/judge | 归一化字符串相等；多选需全对 | 56-64 |
| fill（含旧 calc） | 单空比 `answer`；多空按 `|` 分割逐空比 `blank_answers`；先精确后数字容差 | 67-106 |
| match | 主判据 `(左idx,右idx)` 集合，顺序无关；仅右侧文本重复时回退文本判分 | 122-180 |
| sort | 顺序索引串全等 | 183-196 |
| reading | `score=round(正确数/子题数*100)`，`stars=round(比例*5)`，≥60 通过 | 199-217 |
| code | 沙箱实跑 + LLM 评星 | 220-270 |

- 数字容差：fill 默认 `tolerance=0.01`（`models.py:125`）；`normalize_output` 大小写不敏感。

## 3. 应用题文（essay）降级说明 ⚠️

`_judge_essay`（`exam.py:109-119`）**实际并未调用 LLM**，仅按字数降级：
- ≥10 字 → 3 星 / 60 分 /「有作答，等待老师点评。」
- 否则 0 分。

> 文档/注释声称「调 LLM 评星」与实现不符，后续可接 LLM 或保留人工批改。

## 4. 阅读理解（reading）

- `content` = 文章正文；`reading_items` = 子题数组（当前子题均为 choice）。
- 子题结构：`{"type":"choice","q":...,"options":[...],"answer":"索引","explanation":...}`。
- 顶层 `answer` 为子题正确索引逗号串（如 `"0,1"`），后台可从子题自动生成。
- 整篇进错题本；判分按子题正确比例。
