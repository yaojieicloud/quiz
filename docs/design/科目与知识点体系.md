## 1. 三级知识结构

```
Subject（科目）
  └─ Topic（课 / 知识点）   ← 掌握度、薄弱分析的最小粒度
       └─ Question（题目）
```

- **文化类**（语文/数学/英语，`category="culture"`）：Topic 用 `unit`（单元）+ `name`（课时）两级组织，前端按 unit 折叠。
- **编程类**（Python，`category="programming"`）：Topic 扁平组织，`unit` 留空。

## 2. 数据模型

### subjects（`models.py:45-68`）
| 字段 | 说明 |
|---|---|
| name | 唯一，如 `数学`（注意：不要带年级，年级存 `grade`） |
| description / icon | 描述 / 图标（默认 📚） |
| grade | 年级，如 `三年级` |
| category | `culture` / `programming` |
| sort_order | 排序 |
| allowed_types | JSON，可空；参与组卷/显示的题型白名单 |

### topics（`models.py:71-86`）
`subject_id`(FK) / `name` / `unit`(可空) / `sort_order`。

### questions（`models.py:89-137`）
| 字段 | 说明 |
|---|---|
| subject_id / topic_id | 双 FK 必填 |
| type | 9 种题型之一 |
| content / options / match_options / reading_items | 题干 / 选项 / 连线 / 阅读子题 |
| answer / explanation | 标准答案 / 讲解 |
| difficulty | 默认 1（1简单/2中等/3较难） |
| is_multiple | 是否多选 |
| blank_count / blank_answers / tolerance | 填空空数 / 多空答案 / 数字容差（默认 0.01） |
| expected_output / sample_input | code 题实跑期望输出 / 样例输入 |
| deprecated | 默认 False；弃用题不出卷但保留历史 |

## 3. 科目接口（前缀 `/api`，非 `/api/subjects`）

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/subjects` | 登录 | 返回附加 `question_count` + `available_types` |
| POST | `/subjects` | admin | 新建（重名 400） |
| GET | `/subjects/{id}/topics` | 登录 | 该科目下的课 |
| GET | `/subjects/{id}/units` | 登录 | 按 unit 去重分组（编程类返回 unit=None 一条） |
| POST | `/topics` | admin | 新建课 |
| PUT | `/subjects/{id}` | admin | 改科目（含 allowed_types） |
| DELETE | `/subjects/{id}` | admin | 删科目（`question_count>0` 则 400，须先删题） |
| PUT/DELETE | `/topics/{id}` | admin | 改/删课（同理保护） |

### allowed_types 用法
- 读取：`available_types`（题库实际题型）∩ `allowed_types`，NULL/空即不限制（`subjects.py:25-28`）。
- 写入：空数组归一为 NULL（`subjects.py:95-97`）；`SubjectCreate` 不含该字段，只能 PUT 配置。
- 典型：应用题（essay）仅数学启用；阅读理解（reading）仅语文/英语启用。**组卷时该配置是题型闸门**（见 [组卷与答题流程](组卷与答题流程.md)）。

## 4. 题目接口（前缀 `/api/questions`）

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/` | 登录 | 支持 `subject_id/topic_id/type` 过滤；**答案脱敏**：非 admin 时 code 题 `answer=None`、reading 题剥离子题 answer/explanation |
| POST | `/` | admin | 单题新增 |
| POST | `/batch` | admin | **题目导入接口**，body 为 `list[QuestionCreate]`，返回 `{"created": N}`（无去重、一次性 commit） |
| GET | `/{id}` | admin | 含答案 |
| PUT/DELETE | `/{id}` | admin | 改/硬删 |

## 5. 出题规范与数据源

- 题库 JSON 在 `src/data/`（如 `math_questions.json`、`python_coding_new200.json`、`english_reading_lower.json`、`reading_chinese/c3a_*.json`）。
- 出题模板：`data/template/culture_subject.md`、`question_types.md`、`python_practical.md`、`python_theory.md`。
- **出题铁律**（README）：英语/语文/数学须对齐人教版新课标课本单元与课时，不得杜撰。
- 题库导入已废弃（数据走 ECS，出题走 LLM，见出题模板 `src/data/QUESTION_TEMPLATE.md`）。
