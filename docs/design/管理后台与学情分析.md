## 2. 学情分析接口（`routers/admin.py`，前缀 `/api/admin`）

| 接口 | 返回 |
|---|---|
| `GET /analytics/overview` | `totals`(全局 KPI) / `trend`(近14天) / `trend_by_subject` / `by_subject` / `by_type` / `top_students`(LIMIT10)；过滤 `grade`/`subject_id`（**该接口保留，但前端「学习总览」子页已删，暂无 UI 入口**） |
| `GET /analytics/student/{id}` | `student` / `score_trend` / `by_subject` / `by_topic` / `top_wrong`(wrong_limit∈10/20/30/50) / `recent`(10)；**by_topic/top_wrong 注入 mastery 状态**；`score_trend` 供掌握度全景成绩趋势图 |
| `GET /analytics/weakness` | 双口径（见 [掌握度与学情联动](掌握度与学情联动设计.md)） |
| `GET /analytics/recent-activity?student_id=&subject_ids=&days=&limit=` | **最近刷题动态**（新增 2026-08-21）：`sessions`(近 N 天场次明细：时间/学员/科目/课时列表/题数/得分/档位) + `by_topic`(各课累计答题量聚合：学员/科目/课时/题数/正确率)。**过滤条件（student_id / subject_ids）下沉 SQL 层**，先 WHERE 再 `order_by + limit` |
| `POST /analytics/report` | AI 周报（见 [AI 评分](AI评分与学情报告.md)） |

> `recent-activity` 聚合逻辑抽为共享函数 `build_recent_activity(db, student_id, subject_ids, days, limit)`，admin 与学员端两路由复用。
> `GET /api/admin/mastery?tier=&subject_ids=`：`subject_ids` 支持逗号分隔多科目（空=全部），返回 `subjects[]` + `topics[]`（每条带 `subject_name`），读 `student_mastery` 表。

学员端复用接口：
- `GET /api/exam/recent-activity?days=`（`exam.py`，student_id 固定当前用户）：学员端「最新动态」页用，返回与 admin 相同结构。
- `GET /api/mastery/me`：学员端「掌握度全景」页用（学员固定，读表）。

## 3. 学员答题记录管理（`admin.py:343-464`）

| 接口 | 说明 |
|---|---|
| `GET /students` | 学员列表（exam_count / last_exam_at） |
| `GET /students/{id}/records` | 列表（不含明细） |
| `GET /records/{id}` | 全明细（`_admin_record_out` **不隐藏 code 参考答案**） |
| `PUT /answer-records/{id}` | 改 llm_score(0-100)+评语，自动 `llm_stars=score//20`、`is_correct=score>=60`，并重算 record 的 correct/wrong/score |
| `DELETE /records/{id}` | 删记录（连带明细） |

前端：`deleteRecord` / `editAnswerRecord` / `saveEditAnswer` / `fillStuDrawer`。

## 4. 学员掌握度矩阵（`admin-mastery.html` + `js/admin-mastery.js`）

- 接口 `GET /api/admin/mastery?tier=&subject_ids=`：返回 `subjects[]` + `topics[].cells{student_id:{tier:{status,rate,coverage}}}` + 班级 `counts/pass_rate/mastery_rate`。**读 `student_mastery` 表**。
- 渲染：**行=课程、列=每位学员**，每格为状态色块（通过绿/精通橙/需复习红/练习中蓝/未开始灰）+ 覆盖度%。
- 点格 → 该学员此课详情。
- 顶部 KPI：平均通过率 / 精通率。

> 只有两个小学员（瑶瑶#2 / 诺诺#4），视图落实到人，不做"班级汇总"。

## 4.1 掌握度全景 / 最近动态（`admin.html` 学情分析子页，复用 `js/analytics-shared.js`）

- **掌握度全景**：筛选「学员（全部/单选）+ 科目（chip 多选，默认 Python基础实操）+ 档位」；柱状图**只显示覆盖度%（=精通度）**，颜色分级（橙≥80 / 绿≥50 / 蓝≥20 / 灰<20），动态高度（每课约 26px，>20 课加滚动）；下方掌握度矩阵表；选单学员时再显示「成绩趋势」折线图。
- **最近动态**：筛选「学员 + 科目（chip 多选）+ 时间范围（1/3/7/14/30 天）」；各课答题量柱状图**占满整行**（已删「各学员答题量」饼图）+ 场次明细表。
- 两子页均引用 `js/analytics-shared.js` 共享组件（`renderMasteryCoverageChart` / `renderMasteryMatrix` / `renderRecentTopicChart` / `renderRecentSessions` / `populateSubjectChips` 等），与学员端共用同一套代码。
