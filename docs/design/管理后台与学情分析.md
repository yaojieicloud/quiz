## 1. 管理后台结构（`admin.html`）

12 个 tab（`admin.html:107-120`）：科目与章节、题目管理、学员答题、批量导入、SQL 运维、数据备份、学情分析、AI周报、奖励管理、科目积分、LLM日志、学员掌握度。后 4 个为 **iframe 内嵌**子页（`?embed=1`）：
- `admin-reward.html`（奖励管理）
- `admin-subject-points.html`（科目积分）
- `admin-llm.html`（LLM 日志）
- `admin-mastery.html`（学员掌握度矩阵）

> embed 模式：`common.js#renderTopbar` 在 `?embed=1` 或处于 iframe 内时不渲染顶栏，避免双导航。

学情分析内 3 个子 tab：总览 / 学员档案 / 薄弱分析。

## 2. 学情分析接口（`routers/admin.py`，前缀 `/api/admin`）

| 接口 | 行号 | 返回 |
|---|---|---|
| `GET /analytics/overview` | L498 | `totals`(全局 KPI) / `trend`(近14天) / `trend_by_subject` / `by_subject` / `by_type` / `top_students`(LIMIT10)；过滤 `grade`/`subject_id` |
| `GET /analytics/student/{id}` | L605 | `student` / `score_trend` / `by_subject` / `by_topic`(HAVING≥2 升序 LIMIT20) / `top_wrong`(wrong_limit∈10/20/30/50) / `recent`(10)；**by_topic/top_wrong 注入 mastery 状态**（L652-655, L668-671） |
| `GET /analytics/weakness` | L709 | 双口径（见 [掌握度与学情联动](掌握度与学情联动设计.md)） |
| `POST /analytics/report` | L885 | AI 周报（见 [AI 评分](AI评分与学情报告.md)） |

`GET /api/stats/overview`（`stats.py`）：学员端 `stats.html` 用，仅统计 `finished_at != None`，返回 total_exams / avg_score / best_score / total_wrong + 分科目明细。

## 3. 学员答题记录管理（`admin.py:343-464`）

| 接口 | 说明 |
|---|---|
| `GET /students` | 学员列表（exam_count / last_exam_at） |
| `GET /students/{id}/records` | 列表（不含明细） |
| `GET /records/{id}` | 全明细（`_admin_record_out` **不隐藏 code 参考答案**） |
| `PUT /answer-records/{id}` | 改 llm_score(0-100)+评语，自动 `llm_stars=score//20`、`is_correct=score>=60`，并重算 record 的 correct/wrong/score |
| `DELETE /records/{id}` | 删记录（连带明细） |

前端：`deleteRecord` / `editAnswerRecord` / `saveEditAnswer` / `fillStuDrawer`。

## 4. 学员掌握度矩阵（`admin-mastery.html` + `js/admin-mastery.js`）

- 接口 `GET /api/admin/mastery?subject_id=`：返回 `students[]` + `topics[].cells{student_id:{status,rate,coverage}}` + 班级 `counts/pass_rate/mastery_rate`。
- 渲染：**行=课程、列=每位学员**，每格为状态色块（通过绿/精通橙/需复习红/练习中蓝/未开始灰）+ 正确率。
- 点格 → `mastery.html?student_id=X&topic=Y` 新标签打开该学员此课详情。
- 顶部 KPI：平均通过率 / 精通率。

> 只有两个小学员（瑶瑶#2 / 诺诺#4），视图落实到人，不做"班级汇总"。
