# 答题后精通度变化展示

> REQ-N: 答题后结果页显示精通度变化（提升几点 / 未提升说明原因）
> 版本: v1.0 | 2026-08-28

## 1. 需求背景

学员提交答卷后，结果页只显示分数、对错、积分，没有显示本次答题对精通度的影响。学员无法直观感受到自己的进步或不足。

**目标**：在答题结果页（分数+积分下方）新增"精通度变化"区域，逐课展示本次答题带来的精通度变化，未提升时用小朋友看得懂的语言说明原因。

## 2. 现状分析

### 后端

`submit_exam`（`src/routers/exam.py:631`）提交流程已具备：
1. 判分 → 落 `answer_records`
2. `compute_mastery_for_topics` 重算涉及课程精通度
3. `upsert_student_mastery` 写入 DB
4. 返回 `mastery_rewards`（新精通奖励列表）

**缺失**：upsert 前没有快照旧精通度数据，无法计算 delta。

### 前端

`showResult(record)`（`src/static/quiz.html:1295`）渲染结果页，包含：
- 分数横幅（得分/对错/用时/积分）
- 答题详情（逐题展开）
- 操作按钮（再做一套/查看记录/错题本）

**缺失**：没有精通度变化区域。

### 精通度计算（`src/core/mastery.py`）

三硬门槛：
```
精通 mastered = N >= max(Q×0.8, 10) AND R >= 90% AND Ccov >= 80%
```

其中：
- N = 累计答题次数
- R = 最近100题正确率
- Ccov = 不重复题数D / 题库总量Q（覆盖度）

    """精通度变化（答题前后对比）"""
    topic_name: str             # 课程名

#### 3.1.2 精通度百分比计算函数

在 `core/mastery.py` 新增工具函数：

```python
def calc_mastery_pct(status, rate, coverage, N, Q):
    """计算精通度百分比（0-100），供前端展示。
    
    逻辑：
    - status == 'mastered' → 100
    - 否则取 min(R/90%, Ccov/80%, N/threshold) × 100，封顶 99
    - 无答题 → 0
    """
    if status == "mastered":
        return 100
    if N == 0 or Q == 0:
        return 0
    thr_n = max(int(Q * MASTER_ANSWERS_RATIO), MIN_ANSWERS_FLOOR)
    rate_ratio = min(rate / (MASTER_RATE * 100), 1.0)
    cov_ratio = min(coverage / (MASTER_COV * 100), 1.0)
    n_ratio = min(N / thr_n, 1.0)
    return min(rate_ratio, cov_ratio, n_ratio) * 100
```

瓶颈诊断函数：

```python
def diagnose_bottleneck(rate, coverage, N, Q):
    """诊断未提升的瓶颈原因，返回简化文案 key。
    
    优先级：正确率 > 覆盖度 > 做题数（按距门槛差距从大到小）
    """
    if Q == 0:
        return None
    thr_n = max(int(Q * MASTER_ANSWERS_RATIO), MIN_ANSWERS_FLOOR)
    rate_gap = max(0, MASTER_RATE * 100 - rate)        # 正确率缺口
    cov_gap = max(0, MASTER_COV * 100 - coverage)       # 覆盖度缺口
    n_gap = max(0, thr_n - N)                            # 做题数缺口
    
    if rate_gap <= 0 and cov_gap <= 0 and n_gap <= 0:
        return None  # 全部达标，应该已精通
    
    # 返回差距最大的一项
    gaps = {"rate": rate_gap, "coverage": cov_gap, "count": n_gap}
    return max(gaps, key=gaps.get)
```

#### 3.1.3 submit_exam 改动

在 `src/routers/exam.py` 的 `submit_exam` 中：

```python
# ---- upsert 前：快照旧精通度 ----
prev_mastery = {}
if topic_ids:
    for r in db.query(StudentMastery).filter(
        StudentMastery.student_id == user.id,
        StudentMastery.tier == record.tier,
        StudentMastery.topic_id.in_(topic_ids),
    ).all():
        prev_mastery[r.topic_id] = (r.status, r.rate, r.coverage, r.answered_count, r.topic_total)

# ---- 原有 upsert 逻辑 ----
computed = compute_mastery_for_topics(db, user.id, pairs)
upsert_student_mastery(db, user.id, computed)

# ---- 计算 delta ----
mastery_deltas = []
topic_name_map = {t.id: t.name for t in db.query(Topic).filter(Topic.id.in_(topic_ids)).all()}
for (tid, tier, subject_id, status, rate, coverage, N, D, C, Q) in computed:
    prev = prev_mastery.get(tid)
    if prev:
        prev_status, prev_rate, prev_cov, prev_N, prev_Q = prev
    else:
        prev_status, prev_rate, prev_cov, prev_N, prev_Q = "not_started", 0, 0, 0, Q
    
    before_pct = round(calc_mastery_pct(prev_status, prev_rate, prev_cov, prev_N, prev_Q))
    after_pct = round(calc_mastery_pct(status, rate, coverage, N, Q))
    delta = max(0, after_pct - before_pct)
    newly_mastered = (status == "mastered" and prev_status != "mastered")
    
    bottleneck = None
    if delta == 0 and not newly_mastered:
        bottleneck = diagnose_bottleneck(rate, coverage, N, Q)
    
    mastery_deltas.append({
        "topic_name": topic_name_map.get(tid, f"课#{tid}"),
        "before_pct": before_pct,
        "after_pct": after_pct,
        "delta": delta,
        "newly_mastered": newly_mastered,
        "bottleneck": bottleneck,
    })
```

`_record_to_out` 签名新增 `mastery_deltas` 参数，传入响应。

#### 3.2.2 单课渲染逻辑

```javascript
function renderMasteryDelta(d) {
  if (d.newly_mastered) {
    // 🎉 新达到精通
    return `
      <div class="delta-card delta-mastered">
        <div class="delta-emoji">🎉</div>
        <div class="delta-info">
          <div class="delta-topic">${esc(d.topic_name)}</div>
          <div class="delta-text">恭喜！已精通！</div>
        </div>
        <div class="delta-pct">100%</div>
      </div>`;
  }
  if (d.delta > 0) {
    // 精通度提升
    return `
      <div class="delta-card delta-up">
        <div class="delta-emoji">📈</div>
        <div class="delta-info">
          <div class="delta-topic">${esc(d.topic_name)}</div>
          <div class="delta-text">精通度 +${d.delta}%！继续加油！</div>
        </div>
        <div class="delta-pct">${d.after_pct}%</div>
      </div>`;
  }
  // 未提升 — 根据瓶颈原因显示
  const reasonMap = {
    rate: "正确率还不够，争取答对更多！",
    coverage: "做过的题型还不够多样，试试更多不同的题！",
    count: "做得还太少，再多练几次！",
  };
  const reason = reasonMap[d.bottleneck] || "还需要加油哦，多做几套题！";
  return `
    <div class="delta-card delta-same">
      <div class="delta-emoji">💪</div>
      <div class="delta-info">
        <div class="delta-topic">${esc(d.topic_name)}</div>
        <div class="delta-text">${reason}</div>
      </div>
      <div class="delta-pct">${d.after_pct}%</div>
    </div>`;
}
```

| `rate` | 正确率 < 90% 且差距最大 | "正确率还不够，争取答对更多！" |
