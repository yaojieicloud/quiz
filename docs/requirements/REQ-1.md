# REQ-1 统一掌握度/最近动态柱状图样式为横向响应式

## 1. 原始描述
> 我很喜欢 qyn_mastery_chart.html 这个柱状图的样式（横向响应式，每课一行），在掌握度和最近动态的柱状图样式就不是很友好，尤其在窄屏或手机，挤在一起。柱状图样式统一使用这个样式，记录到文档中，同时更新现有柱状图的样式。

## 2. 需求目标
- 把「掌握度·各课覆盖度柱状图」和「最近动态·各课答题量柱状图」从 ECharts 纵向 bar 改造为**横向响应式 CSS 进度条**样式（每课一行：标签 + 横向条 + 数值，永不重叠）
- 解决窄屏/手机上课程多时柱状图**挤在一起、标签重叠、看不清**的问题
- 统一学员端 + 管理端两处界面的柱状图视觉样式，保持一致

## 3. 功能范围
### 3.1 要做（In Scope）
- 改造 `renderMasteryCoverageChart`（掌握度·各课覆盖度柱状图）为横向 CSS 柱
- 改造 `renderRecentTopicChart`（最近动态·各课答题量柱状图）为横向 CSS 柱
- 覆盖 3 个页面、4 个图表实例：
  - 学员端 `static/mastery.html`（掌握度全景）
  - 学员端 `static/stats.html`（最新动态）
  - 管理端 `static/admin.html`（掌握度全景 + 最近动态）
- 新增横向柱的 CSS 样式（进度条 track/fill/标签/数值 + 响应式断点）
- 同步更新相关文档

### 3.2 不做（Out of Scope）
- **不改造**掌握度**矩阵表**（`renderMasteryMatrix`）
- **不改造**成绩**趋势折线图**
- **不改造**最近答题**场次明细表**（`renderRecentSessions`）
- **不删除 ECharts**：其余图表（矩阵、曲线、其他页面统计）仍用 ECharts
- **不改后端 API**：继续使用现有 `/api/admin/mastery`、`/api/exam/recent-activity`、`/api/admin/analytics/recent-activity` 返回的数据结构

## 4. 非功能约束
- 兼容性：前端原生 HTML/JS，无构建步骤；**不新增第三方依赖**（纯 CSS 实现，不依赖 ECharts 的这两图）
- 响应式：窄屏（<480px）行高/字体自适应，宽 bar 百分比自适应，数值不溢出
- 交互：保留数据提示（tooltip 用 HTML title 或内联文本替代 ECharts tooltip）；保留「精通 80% 门槛刻度线」的视觉提示
- 数据量：掌握度课数可达 20+，需支持纵向滚动、行高固定不挤压

## 5. 影响范围
- 涉及模块：前端学情分析共享组件 + 管理/学员端页面
- 涉及现有文件：
  - `src/static/js/analytics-shared.js`（核心：2 个渲染函数重写）
  - `src/static/css/common.css`（新增横向柱样式）
  - `src/static/mastery.html`、`src/static/stats.html`、`src/static/admin.html`（图表容器适配）
- 上下游影响：3 个页面共享 `analytics-shared.js`，改组件函数即全局生效；不涉及后端/接口/数据库

## 6. 风险与约束
- 风险点1：`analytics-shared.js` 被 3 页面复用，改写须保证**同样的入参结构**（`d.topics`/`d.by_topic`）兼容，避免页面报错
- 风险点2：mastery 页有「单学员/多学员」切换，掌握度柱状图是「所选学员平均覆盖度」，需保留该聚合逻辑
- 风险点3：移动端隐藏 ECharts tooltip 后，需保证数值仍可读（保留数值标签）
- 风格约束：遵循项目前端约定（原生、中文注释、类名清晰）

## 7. 验收标准
- 标准1：掌握度柱状图在学员端 `mastery.html` + 管理端 `admin.html` 均显示为**横向进度条**（每课一行），不再横向挤压
- 标准2：最近动态柱状图在学员端 `stats.html` + 管理端 `admin.html` 均显示为**横向进度条**，标签完整可读
- 标准3：窄屏（<480px）下柱状图布局不破、不重叠、条宽自适应
- 标准4：掌握度柱状图保留「覆盖度值」标签 + 精通 80% 门槛线；最近动态保留「题数 + 正确率」标签
- 标准5：其余图表（矩阵表、成绩趋势折线、场次明细表）仍为原样式（ECharts），未受影响
- 标准6：无控制台报错，数据加载正常
