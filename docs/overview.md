# 需求总览

> it-workflow 初始化生成（2026-08-24）。内容依据 README / docs/design / 代码逆向梳理；当前无 REQ 编号需求。

## 项目目标
- 为小学小朋友提供低门槛刷题系统：做题赚积分 → 大转盘/直兑奖励，形成正向激励闭环
- 家长可绑定孩子、查看学情；管理员可管理题库并做数据化学情分析
- 题目内容对齐人教版新课标课本（2024 秋季改版，出题铁律）

## 非功能约束
- 性能：单人低并发场景（小学生刷题），SQLite 单文件足够，暂无并发压力设计
- 安全：JWT + 角色网关；密钥走环境变量/quiz-data/*.txt，禁止入代码与仓库；写运维接口先备份；注册需 regkey（当前未开放自由注册）
- 兼容性：前端原生 HTML/JS 无构建；ECharts CDN 失败降级；时间统一 UTC 存储 + +00:00 输出（core/times.py）
- 内容合规：出题铁律（严格遵循人教版新课标 2024 秋季改版教材）
