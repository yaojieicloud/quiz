# Quiz 系统功能评估与未来规划

> 评估时间：2026-08-06

## 现状总结

Quiz 系统已实现从出题到评估的完整学习闭环，覆盖 9 种题型、人教版新课标对齐、LLM 智能评分、学情分析四大模块、AI 周报等功能。系统已部署上线，多名学生实际使用。

### 已完成核心功能

1. **智能出题系统**：9 种题型（选择/判断/填空/解答/编程/连线/排序/阅读理解/应用题）+ 人教版新课标对齐 + 2000+ 题库
2. **智能评估系统**：客观题自动判分 + 编程题沙箱运行 + LLM 评星（1-5 星）+ 反馈生成
3. **错题管理系统**：错题自动收集 + 错题重做 + 掌握标记 + 反复错题榜
4. **学情分析系统**：学习总览/学员档案/薄弱分析/AI 周报 + 年级科目两级筛选 + 趋势图表
5. **管理控制系统**：管理员后台 + 学员管理 + 题库管理 + 数据备份

## 功能缺口分析

### 🔴 P0：直接影响学习效果

#### 1. 个性化学习路径缺失
- **现状**：孩子只能"自由组卷"或"随机挑战"，没有针对性练习
- **问题**：薄弱的知识点没得到针对性强化
- **建议**：基于错题本 + 薄弱知识点，**自动推荐"今日必练"**（5-10 题针对性练习）

#### 2. 学习节奏缺失
- **现状**：没有"每天该学什么"的规划
- **问题**：孩子容易三天打鱼两天晒网，或者一口气刷完然后忘记
- **建议**：增加"每日学习任务"（按课时推进，每天 X 题）

### 🟡 P1：影响家长掌控力

#### 3. 家长主动通知缺失
- **现状**：周报要主动打开后台看，AI 周报要手动生成
- **问题**：家长被动，无法及时发现孩子异常（连续几天没学、某科突然下滑）
- **建议**：**PushPlus 主动推送**（每日学习简报 + 异常告警，复用现有 PC 监控的 PushPlus 通道）

#### 4. 多孩子横向对比缺失
- **现状**：学员档案是单孩子视角
- **问题**：多个孩子时，无法一眼看出谁学得好谁需要关注
- **建议**：增加"孩子对比面板"（多孩子成绩趋势并排、薄弱点对比）

#### 5. 学习时长/专注度监控缺失
- **现状**：有 `duration_seconds` 字段但前端没展示
- **问题**：无法判断孩子是认真学还是敷衍刷
- **建议**：展示"每题平均用时"、"学习时段分布"（识别是否深夜刷）

### 🟢 P2：锦上添花

#### 6. 成就/激励机制缺失
- **现状**：有星级评分但无累积成就感
- **建议**：勋章系统（连续 7 天打卡、满分王、进步之星）、排行榜（可选匿名）

#### 7. 知识点关联图谱缺失
- **现状**：薄弱知识点是平铺列表
- **建议**：知识点掌握热力图（按单元/课时，一眼看出哪里红哪里绿）

#### 8. 家长端独立入口缺失
- **现状**：家长要登录管理员后台
- **建议**：家长专属视图（只看自己孩子的数据，更简洁）

## 实施建议

### 建议实施顺序（投入产出比最高）

| 优先级 | 功能 | 预计工作量 | 价值 |
|--------|------|-----------|------|
| 1 | **每日学习任务**（home.html 加"今日推荐"卡片 + 后端推荐接口） | 1-2 天 | 建立学习节奏 |
| 2 | **PushPlus 每日学习简报**（复用 PC 监控的推送机制） | 半天 | 家长主动掌控 |
| 3 | **多孩子对比面板**（admin.html 新增对比子面板） | 1 天 | 横向对比分析 |
| 4 | **知识点掌握热力图**（ECharts heatmap） | 1 天 | 直观掌握情况 |

### 其他考虑

- **数据增长**：当前 SQLite 适合单机部署，如果用户量增长，可能需要迁移 PostgreSQL
- **移动端适配**：当前 PC 端体验良好，移动端可能需要专门优化
- **多语言支持**：如果未来扩展到其他学科（英语等），可能需要多语言题库

---

## 待决策事项

1. **是否引入每日学习任务机制？** 这是帮助孩子建立学习习惯的关键功能
2. **是否接入 PushPlus 主动推送？** 让家长从"被动查看"变为"主动接收"
3. **是否需要多孩子对比视图？** 如果管理多个孩子，这个功能很实用
4. **是否需要家长独立入口？** 还是继续用管理员后台统一管理

## 技术栈备注

- **后端**：FastAPI + SQLAlchemy 2.0 + SQLite + JWT
- **前端**：原生 HTML/CSS/JS + ECharts
- **部署**：Docker + 阿里云 ECS
- **LLM**：阿里云百炼（qwen3.7-plus）+ DeepSeek（代码评分）
- **推送**：PushPlus（已有基础设施，可复用）
