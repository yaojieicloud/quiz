# 语文阅读理解（reading 题型）出题规范

> 生成目标：三年级语文，每课 5 篇阅读理解，题型 `reading`。
> 输出格式：纯数组 JSON（文化类导入格式），每篇 = 1 道 reading 题。

## 一、JSON 格式（严格遵守）

```json
[
  {
    "type": "reading",
    "topic_name": "1 大青树下的小学",
    "unit": "上册-第一单元 校园生活",
    "content": "短文正文，100~200字。可用 \\n 分段。",
    "options": null,
    "reading_items": [
      { "type": "choice", "q": "问题1", "options": ["A","B","C","D"], "answer": "0", "explanation": "讲解" },
      { "type": "choice", "q": "问题2", "options": ["A","B","C","D"], "answer": "2", "explanation": "讲解" }
    ],
    "answer": "0,2",
    "explanation": "",
    "difficulty": 1
  }
]
```

硬性要求：
1. `topic_name` 和 `unit` 必须与任务给定的清单**逐字一致**（含空格和全角标点）
2. `reading_items` 每篇 2~3 个子题，子题 `type` 固定 `"choice"`，选项固定 4 个
3. 子题 `answer` 是正确选项索引字符串（"0"~"3"），顶层 `answer` 是子题索引逗号串（如 `"0,2"`）
4. 所有文本 UTF-8；`content` 分段用 `\n`
5. 选项内容不能雷同、不能有歧义；正确答案必须能从文中找到依据
6. `difficulty`：基础信息查找题为主的篇章填 1，有概括/推断的填 2

## 二、短文内容要求（重要）

1. **全部原创**：只围绕课文的主题/题材写新短文，**严禁照抄人教版课文原文或任何出版物内容**
2. 长度 100~200 字，语言适合三年级小学生（常用字为主，避免生僻词）
3. 同课 5 篇要题材多样：记叙文、童话寓言、写景状物、科普小品、生活故事等穿插
4. 主题与课时呼应（如《秋天的雨》一课写秋天相关短文；《赵州桥》一课写传统文化/建筑相关）
5. 古诗类课时（"古诗三首"）不考原诗，写与诗意相关的短文（如季节、思乡、童趣主题）
6. "语文园地"和"习作"课时：写与该单元主题相关的综合短文即可

## 三、子题设计要求

每篇 2~3 题，题型分布参考：
- **找信息**：文中直接能找到的事实（谁、哪里、什么时候）
- **理解词句**：某个词在文中的意思/指代
- **概括主旨**：短文主要讲了什么
- **简单推断**：根据文意推断人物心情/接下来会发生什么

讲解（explanation）用小朋友能懂的话说清依据，如："文中第二句写了……所以选A。"

## 四、输出文件

写入指定路径，文件名在任务中给出。**只输出合法 JSON 数组，不要包 markdown 代码块**。
写完后自查：JSON 可被解析、answer 与子题索引一致、topic_name/unit 与清单一致。
