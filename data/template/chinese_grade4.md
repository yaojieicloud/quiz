## 题目 JSON 格式规范

### 基本格式

```json
[
  {
    "type": "choice",
    "topic_name": "1 观潮",
    "unit": "上册-第一单元",
    "content": "《观潮》描写的是哪里的大潮？",
    "options": ["长江三峡", "钱塘江", "黄河壶口", "西湖"],
    "answer": "1",
    "explanation": "《观潮》描写的是钱塘江大潮，是天下奇观。",
    "difficulty": 1
  }
]
```

### 单元命名规范

| 册次 | 格式 |
|------|------|
| 上册 | `"上册-第一单元"` ~ `"上册-第八单元"` |
| 下册 | `"下册-第一单元"` ~ `"下册-第八单元"` |

### 课时命名规范

- 精读课文：`"1 观潮"`、`"8 古诗三首"`
- 略读课文：`"3* 秋夜的江上"`（带星号）
- 口语交际：`"口语交际：我们与环境"`
- 习作：`"习作：推荐一个好地方"`
- 语文园地：`"语文园地一"` ~ `"语文园地八"`
- 古诗三首分开：`"8 古诗三首（暮江吟）"`、`"8 古诗三首（题西林壁）"`、`"8 古诗三首（雪梅）"`

### 阅读理解题格式

```json
{
  "type": "reading",
  "topic_name": "1 观潮",
  "unit": "上册-第一单元",
  "content": "那条白线很快向我们移来……",
  "options": null,
  "reading_items": [
    { "type": "choice", "q": "潮来前江面是什么样子？", "options": ["波涛汹涌", "风平浪静", "雾气弥漫", "下着大雨"], "answer": "1", "explanation": "潮来前江面风平浪静。" }
  ],
  "answer": "1",
  "explanation": "",
  "difficulty": 2
}
```

## 出题重点说明

### 第一单元：边塞/自然/现代诗
- **观潮**：钱塘江大潮，按时间顺序（潮来前→潮来时→潮来后）描写
- **繁星**：观察角度变化（睡前→望台上→深夜）

### 第二单元（提问策略）
- 引导学生从不同角度提问（内容、写法、启示）
- 蝙蝠和雷达的因果关系

### 第三单元：观察
- 古诗三首：暮江吟（写景）、题西林壁（哲理）、雪梅（借物喻理）
- 爬山虎的脚：连续观察方法
- 蟋蟀的住宅：动物观察

### 第四单元：神话
- 盘古开天地：创造世界
- 精卫填海：坚韧不拔
- 普罗米修斯：盗火造福人类

### 第五单元（习作单元）：把事情写清楚
- 注意事情发展顺序
- 抓住细节描写

### 第六单元：童年
- 牛和鹅：批注阅读，从不同角度理解
- 窝囊的大老虎：童年趣事

### 第七单元：家国情怀
- 边塞诗三首
- 为中华之崛起而读书
- 延安精神

### 第八单元（批注策略）
- 王戎不取道旁李：善于观察思考
- 西门豹治邺：智慧治理
- 故事二则：防微杜渐、持之以恒

## 出题铁律

1. **严格对齐课本**：单元名、课时名必须与课本目录一致
2. **不超纲**：四年级小朋友认知水平，不出超纲题
3. **题型限制**：四年级语文支持 choice/judge/fill/essay/match/sort/reading
4. **古诗标题唯一**：三首古诗要分开标题，如"8 古诗三首（暮江吟）"
