## 四年级上册目录结构（人教版 2024 新课标）

> 7 单元 + 3 综合实践。ECS 现有 9 个课程名称如下：

| topic_name（= unit） | 类型 | 核心知识点 |
|---------------------|------|-----------|
| 万以上数的认识 | 计算/概念 | 计数单位（万/十万/百万/千万/亿）、数位顺序表、读写法（先分级）、大小比较（位数不同看位数，位数相同从最高位比）、改写（万/亿作单位）、近似数（四舍五入） |
| 角的度量 | 图形 | 线段/射线/直线（2 个端点/1 个端点/0 个端点）；角的认识（顶点/边）；角的度量（量角器）；角的分类：锐角(<90°)、直角(=90°)、钝角(>90°)、平角(=180°)、周角(=360°)；画角 |
| 多位数乘两位数 | 计算 | 三位数×两位数笔算（竖式步骤）；因数中间/末尾有 0 的乘法；积的变化规律（一个因数不变，另一个扩大 n 倍，积也扩大 n 倍）；数量关系：单价×数量=总价、速度×时间=路程 |
| 加法模型和乘法模型 | 应用 | 加法模型：部分+部分=整体；乘法模型：每份数×份数=总数；简单实际问题建模；乘法交换律、结合律、分配律（文字表述版，不出字母表达式） |
| 平行四边形和梯形 | 图形 | 平行（同一平面内不相交）；垂直（相交成直角）；平行四边形（两组对边平行）；梯形（只有一组对边平行）；高（平行线间的垂线段）；认识组合图形 |
| 条形统计图 | 统计 | 条形统计图特点（1 格代表 1 / 1 格代表多）；读统计图（读标题/横轴/纵轴/数据）；数据分析（最多/最少/相差多少）；预测趋势 |
| 复习与关联 | 综合 | 全册整合复习；知识网络图；易错题整理 |
| 1亿有多大 | 综合实践 | 感受 1 亿的大小；用"计算→推理→感受"的方法（1 亿张纸摞起来多高？1 亿颗大米有多重？） |
| 寻找宝藏 | 综合实践 | 综合运用方向、位置、测量解决问题；描述路线（东南西北/前后左右）；用量角器测量角度 |

## 出题前知识点清单模板

```markdown
## 出题课时：角的度量
- 来源：人教版 四年级 上册 第三单元
- 核心知识点（3-7 条）：
  1. 线段有 2 个端点，射线有 1 个端点，直线有 0 个端点
  2. 角的度量用量角器，读刻度注意看内圈还是外圈
  3. 锐角<90°，直角=90°，钝角>90°
  4. 会画指定度数的角
- 拟用题型：choice + judge + calc
- 拟出题数：每种 3 道，共 9 道
- 检查项：
  - [ ] 不超纲（不出平角/周角作比较的刁钻题）
  - [ ] 不串课（不出后续"平行四边形"相关题）
  - [ ] 计算题答案实跑验证
```

---

## 出题铁律

1. **不超纲**：4 年级小朋友认知水平；只涉及本单元已教知识点
2. **计算题答案必须实跑验证**：用 Python/计算器跑一遍再填 answer
3. **不出字母表达式**：乘法分配律等用文字描述，不出现 `a×(b+c)=a×b+a×c`
4. **图形题可出作图题描述**：描述作图步骤，答案写操作描述
5. **应用题贴近生活**：用小明/小红/学校/超市等场景，不出成人化商业题
6. **讲解用图示或生活比喻**：如"角的开口大小"
7. **连线题去重约束**：左右两侧各自唯一（见 `question_types.md`）
